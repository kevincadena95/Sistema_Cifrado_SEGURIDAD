Bienvenido al Sistema de Cifrado

Esta aplicación está diseñada para conocer y utilizar diferentes métodos de cifrado de información, permitiendo proteger datos mediante técnicas de criptografía.

Cifrado Simétrico

Permite cifrar y descifrar información utilizando una misma clave secreta. Podrás ingresar texto o cargar documentos para proteger su contenido.

Cifrado Asimétrico
